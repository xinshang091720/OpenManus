# Revit IFC 标识赋值说明

## 这项能力解决什么问题

`revit_run_ifc_assignment` 读取活动 Revit 模型中的构件，按深圳标准 `109003` 查询 IFC 标识候选，完成分组匹配、批量写入，并把修改后的模型安全另存。它改变 Revit 模型，不是 SZ-IFC 报建自检工具。

深圳 BIM 要求强调模型信息可识别、可交换和可检查。标识赋值的业务目的，是让交付构件具有正确的 IFC 语义；专业代码和文件名只是沟通线索，不是判断模型是否可以处理的硬门槛。

## 使用前需要知道的信息

- 用户明确提供的 RVT 绝对路径，或 history 中最近一次成功操作记录的模型检查点。
- 用户确认的模型专业：`AR/ST/AC/PD/EL`，或建筑、结构、通风空调、给排水、电气。
- Revit 及本项目插件已经可用，目标模型是当前需要修改的模型。

如果用户没有说明专业，唯一且明确的业务代码可以作为候选；IFC 标识写入会修改模型，专业仍不唯一时再询问。不得因文件名拒绝、复制或重命名模型。

当用户明确要求“创建/赋/重新赋 IFC 标识”时（仅在当前消息明确要求赋 IFC 标识时适用；若当前消息是“已加载”、“可以继续”、“质检”、“自检”等，绝不得调用本工具），按以下顺序决定目标：

1. 用户本次明确指定的模型优先。
2. 否则使用 history 中最近一次成功回复记录的唯一模型检查点及已确认专业，直接调用 `revit_run_ifc_assignment`。
3. 若没有唯一检查点，询问一次“是否对当前 Revit 打开的模型赋值，并请确认专业”。

赋值写入的是当前活动 Revit 文档；`rvt_file_path` 只是续办身份和安全另存位置线索。不要为了验证、重新选择或猜测模型而使用通用文件工具读取、遍历或列举项目文件夹。旧插件可能把另存结果写为无后缀文件；这不应触发项目目录扫描。

## 工具会做什么

- `revit_run_ifc_assignment` 把赋值视为一次重建操作：旧 IFC 标识只清理一次，识别、候选查询、批量赋值和另存也各执行一次。
- 返回赋值数量、低置信度分组、保存目录，以及仅在实际检测到时才返回的 `saved_model_path`。
- 当前插件只返回最初未匹配的构件，不要把该数量描述为模型构件总数。
- 需要解释分组和匹配细节时读取 `references/data-flow.md`；排查接口问题时读取 `references/api-contract.md`。

这是可能持续较长时间的串行 Revit 操作。等待工具返回；运行时会周期性提供当前操作和已运行时间。任一阶段失败后当前 Run 结束；若达到两小时，说明最终 Revit 状态未知，不自动清参、识别或写入第二次。

## 什么时候使用

在用户明确要求以下内容时使用：

- 为模型赋 IFC 标识；
- 补充、重建或重新赋值 IFC 标识；
- 检查现有 IFC 标识后由用户确认需要重做。

以下请求本身不表示要赋值（严禁调用 `revit_run_ifc_assignment` 或重新导出）：

- “质检”或“报建自检”；
- 仅导出 IFC；
- 用户回复“已加载”、“已加载，可以继续”、“已准备好”、“已打开”等加载确认；
- 助手上一轮消息已提示用户加载 IFC 并等待确认时；
- 历史中已经完成赋值与导出，而用户要求继续下一阶段。

## 根据历史继续

先读当前 Run 的 `history`，识别已经完成的阶段：

- 历史已经记录赋值成功和已验证的 `saved_model_path`：继续用户要求的下一项，不重复赋值。
- 历史只记录保存目录或旧版本无后缀的模型检查点：把它作为当前活动模型的续办线索，不扫描项目目录；只有用户明确换模型或专业冲突时询问。
- 历史已经记录 IFC 导出路径：用户要求质检但尚未加载时，提示用户在 SZ-IFC 中手动打开该绝对路径；若历史已确认加载或当前收到“已加载，可以继续”、“已加载”、“已准备好”等确认，严禁重新赋值或重新导出，直接调用 `revit_inspect_ifc` 进行自检。
- 上一次赋值结果未知或超时：向用户说明状态未知并确认模型现状，不自动重试写入。

Skill 在新 Run 中再次激活只表示重新加载说明和工具，不表示重新开始业务流程。

## 安全边界

- 所有 Revit 调用保持串行。
- 不覆盖已有交付文件。
- 不擅自复制、重命名或替换用户模型。
- 写入结果未知时不自动重复写入。
- 不启动第二个 Revit 实例；已有实例不可用时请用户处理当前实例。

需要用户操作时，最终回复记录已完成阶段、当前模型或 IFC 的绝对路径、用户要做的动作、完成后的回复方式，以及下一步将调用的业务工具。
