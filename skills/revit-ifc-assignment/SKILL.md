# Revit 深圳 IFC 标识赋值

## 核心工具

- `revit_run_ifc_assignment`：一键复核并批量赋值 IFC 标识。

## 使用准则与连续执行（避免无意义中断）

1. **自主连续执行**：
   - 当用户在任务指令中已明确要求“IFC标识”、“赋参”等操作，且当前活动模型具备明确专业（例如模型文件名包含 `AR/A` 为建筑、`ST/S` 为结构，或用户指令已指明专业），**必须直接激活本技能并调用 `revit_run_ifc_assignment` 执行赋值**，严禁调用 `ask_human` 中断任务去向用户二次确认。
   - 严禁在模型尚未打开时提前向用户询问“是否对即将打开的模型赋值”或“确认专业是否为建筑”。若用户指令在打开模型前就包含了IFC标识需求，应直接先打开模型，当模型文件名明确为 AR/建筑 或用户已指定建筑时，直接连续执行赋值，绝不提前询问。
   - 只有在模型已打开且模型文件名不含明确专业代码且用户未指定专业（或专业代码如 `G` 存在总图/燃气歧义）时，才可调用 `ask_human` 询问专业。
2. **模型路径接续**：
   - 若前序步骤（如房间批量创建）已将模型另存为结果模型（即 `saved_model_path`，通常在 `result` 目录下），后续 IFC 赋值和导出必须基于该另存模型，严禁重新打开初始源模型。
