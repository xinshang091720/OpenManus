### 15. 覆盖 Markdig.Wpf 链接样式 — 彻底修复蓝色正文/链接
- `App.xaml`:
  - 新增命名空间 `xmlns:markdig="clr-namespace:Markdig.Wpf;assembly=Markdig.Wpf"`
  - 新增 `<Style TargetType="Hyperlink" x:Key="{x:Static markdig:Styles.HyperlinkStyleKey}">` — 用 ComponentResourceKey 直接覆盖 markdig.wpf 内部使用的链接样式键
  - 默认颜色 `#555`，无下划线；Hover `#333` 加下划线
  - 问题根因：markdig.wpf 在渲染 `[文本](url)` 时显式设置 `hyperlink.Style = Styles.HyperlinkStyleKey`，该 key 的样式在其 generic.xaml 中空实现，继承了 WPF 系统默认蓝色。全局 Hyperlink 默认样式和 `Markdown.Link.Foreground` 都无法覆盖这个显式赋值。
  - 效果：所有 Markdown 链接（包括列表项中的链接）统一为灰色，不再出现蓝色

### 16. 修复 MarkdView 粗体/链接蓝色问题（改用代码强制覆盖）
- **根因**：MarkdView Light 主题中 `Markdown.Bold.Foreground` = `#4C63EB`（蓝色）、`Markdown.Link.Foreground` = `#4C63EB`（蓝色）。AI 回复的列表项多用 `**粗体**` 包裹标题，导致"正常文字"也显示为蓝色。MarkdView 通过 ThemeManager 在运行时将主题资源合并到 Application.Resources，优先级可能覆盖 App.xaml 的 XAML 静态定义。
- `App.xaml`: 
  - 移除 `xmlns:markdig` 命名空间和 `HyperlinkStyleKey` 样式（MarkdView 不使用 markdig.wpf 的 ComponentResourceKey）
  - 新增 `Markdown.Bold.Foreground` → `#222222` 覆盖
- `App.xaml.cs`:
  - 新增 `OnStartup` 方法，用 **代码直接赋值** (`Resources["key"] = newValue`) 强制覆盖 22 个资源键
  - 代码赋值优先级高于 MergedDictionaries 合并（无论何时加载），确保最终生效
  - 覆盖范围：正文/粗体/链接/标题(3级)/引用(2)/代码块(3)/行内代码(2)/语法高亮(10) — 全部灰调，消除所有蓝色
