## 2026-08-05 AddDialogueHistory 保存内容与显示修复

### 问题
用户反馈历史记录存在两个问题：
1. **内容不完整**：正常回复开头有 "我已分析当前任务，接下来将执行："，但读取历史记录时该句丢失。
2. **字体大小和颜色不对**：历史记录中文件列表（建筑模型/结构模型/CAD图纸）的加粗、颜色等 Markdown 样式与实时回复不一致。

### 根因
昨天把 `AddDialogueHistory` 改为了 `finalAssistantContent`（来自 `run_completed` 的 `final_answer`），希望与 `_history` 保持一致、只保存最终总结。但实际 `run_completed.final_answer` 不包含 `assistant_message` 中 `phase=plan` 推送给用户的前置文本，导致：
- 历史记录丢失了 "我已分析当前任务，接下来将执行："；
- `final_answer` 中的 Markdown 格式与 UI 气泡中实际显示的内容存在差异，重新加载后样式异常。

### 修复（HomeInterfaceVM.cs L846-859）
区分两个历史用途：
- **`_history`（AgentRuntime 上下文）**：继续只保存 `finalAssistantContent`，排除思考/计划过程，只给模型用最终总结。
- **`AddDialogueHistory`（后台聊天记录）**：保存用户实际看到的气泡内容 `currentAiTextBubble.Content`，并经过 `CleanContentSteps` 处理，确保与 UI 显示完全一致。

```csharp
// _history：仅 final_answer，给 AgentRuntime 上下文
_history.Add(new HistoryMessage { Role = "assistant", Content = finalAssistantContent });

// AddDialogueHistory：保存用户看到的完整气泡内容
var displayedContent = !string.IsNullOrWhiteSpace(currentAiTextBubble?.Content)
    ? CleanContentSteps(currentAiTextBubble.Content)
    : finalAssistantContent;
await _accountApi.AddDialogueHistory(..., displayedContent);
```

### 结果
- 历史记录将包含完整的用户可见文本（包括计划前置句）。
- 历史记录加载后渲染效果与实时回复一致（Markdown 加粗、颜色等）。
- AgentRuntime 上下文仍保持精简，只包含 `run_completed` 的 `final_answer`。

### StopCommand 中 AddDialogueHistory 修复 (HomeInterfaceVM.cs L937-943)
- **问题**：`StopCommand`（手动停止）中的 `AddDialogueHistory` 仍用 `finalAssistantContent`，与正常结束逻辑不一致。停止时如果还没收到 `run_completed`，保存内容不完整。
- **修复**：
  1. L580 新增类字段 `public ChatMessage? currentAiTextBubble;`（原为 SendContentCommand 局部变量）
  2. L659 局部变量声明改为赋值给字段：`currentAiTextBubble = aiBubble;`
  3. L937-943 StopCommand 改为使用 `CleanContentSteps(currentAiTextBubble?.Content)`，回退 `finalAssistantContent`
- **结果**：三处 AddDialogueHistory 调用（正常结束 L859、StopCommand L943）统一使用气泡内容，`_history`（L849）仍只保存 `finalAssistantContent`。
