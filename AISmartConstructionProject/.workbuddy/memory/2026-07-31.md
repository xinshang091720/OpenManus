## 安装后窗口无法显示（进程在后台运行）
- **根因**: `HomeInterface.xaml.cs:59` 托盘图标初始化 `new Icon("logo.ico")` 抛 `FileNotFoundException`，安装包未包含 `logo.ico`
- **后果**: 异常被 `App.xaml.cs` 中 `DispatcherUnhandledException += (s, args) => { args.Handled = true; }` 吞掉，窗口无法显示但进程仍在后台运行
- **代码修复**: `HomeInterface.xaml.cs` 添加 `File.Exists` 检查 + `try-catch`，找不到 ico 时不崩溃
- **打包修复**: `package.bat` 增加 `copy logo.ico` 到 publish 目录步骤
- **教训**: 全局异常捕获 `Handled = true` 会掩盖所有 UI 异常，发布后务必检查日志

## http.sys 端口残留修复
- **现象**: 另一台电脑端口 50000 报占用，但 netstat 查不到 → http.sys 内核层残留，不是 TCP 端口
- **修复**: RevitProxyService 改为主动清理模式。Start() 首行调 ClearHttpSysReservation；Dispose() 退出时也清理；清理同时匹配 `+`、`localhost`、`127.0.0.1` 三种 URL 前缀
