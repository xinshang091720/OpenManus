## BeeSync.AgentRuntime 目录分析
- 位置: `BeeSync.AgentRuntime/` (979MB) + `BeeSync.AgentRuntime.zip` (380MB)

## Runtime segfault (0xC0000005) 根因诊断与修复

**问题**: Runtime 启动 3-5 秒后崩溃，退出码 0xC0000005 (ACCESS_VIOLATION)，无 stdout/stderr 输出

**诊断过程**:
1. 确认配置、参数、Token、LLM Key 全部正确，排除应用层问题
2. 读取 WER 报告 `C:\ProgramData\Microsoft\Windows\WER\ReportArchive\AppCrash_BeeSync...\Report.wer`
3. WER 明确指出故障模块: `orchestrator__mypyc.cp312-win_amd64.pyd`，异常偏移 0x3c0f
4. 提取 Python DLL 版本: 3.12.1 (grep)
5. 根因: mypyc 编译的扩展针对不同 CPython 3.12.x 补丁版本编译，ABI 不兼容

**修复**: 禁用所有 10 个 mypyc 编译的 .pyd 模块（重命名为 .pyd.bak），Python 回退到纯 Python 实现:
- `_internal/ada92cb5d92a588d1b93__mypyc.cp312-win_amd64.pyd`
- `_internal/chardet/pipeline/` 下 9 个: ascii, confusion, escape, magic, orchestrator, statistical, structural, utf1632, utf8, validity

修复后 Runtime 成功启动，健康检查通过: `{"status":"ok","runtime_version":"1.0.0","api_version":"1.0"}`

  1. 手动创建 `C:\ProgramData\Anbi\BeeSync\config\mcp.json` (空 mcpServers)
